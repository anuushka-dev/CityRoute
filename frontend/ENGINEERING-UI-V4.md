# CityRoute Engineering Console v4

The Engineering Console is intentionally different from the Product UI.

## Product

Route, Delivery Optimization, Dispatch, and Operations remain independent product workflows.

## Engineering

The engineering console exposes:

- Architecture and source inventory
- Live health/readiness/liveness state
- Live graph state
- Coordinate validation and snapping probe
- Live A* vs Bidirectional A* probe
- Live distance-matrix generation probe
- Live advanced VRP probe
- Live dispatch comparison probe
- Runtime/concurrency/timeout/Redis/lifecycle surfaces
- Supplied benchmark and Phase 11 evidence
- Test inventory without converting source counts into a current pass claim
- Provenance labels: LIVE / PROBE / EVIDENCE

Historical evidence is never rendered as live telemetry.
